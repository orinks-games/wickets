# Glossary: Turkish

Wicket's speaks standard Turkish and addresses the player as "siz" ("Yeni
rekorunuz var"). The register is plain, warm and spoken: a friend in the
parlor talking to you, not a manual. Short sentences, everyday words, no
abbreviations a screen reader would spell out. Do not attach case suffixes
to a placeholder like `{name}`; rephrase so the name stands alone.

Key names (Enter, Escape, Space, Tab, Page Up, F1, the arrow keys Up, Down,
Left and Right, and the rest), game names and people's names stay in
English.
