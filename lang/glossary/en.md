# Glossary: the English terms

Each word below names one thing in Wicket's, and the game always uses the
same word for it. A blind player builds the game from what they hear, so a
second word for the same thing sends them back to work out whether it is
something new. Every translation keeps the same promise: pick one word for
each term, write it in your language's glossary file
(`lang/glossary/<code>.md`), and use it every time.

## Never translate

- **Game names**: Wicket's, every game's name (Nevermore Manor, Fireside
  Patience, Freewheel, Little Rapids and the rest), and the names of special
  events and holiday specials when they are a proper title.
- **People's names**: Mabel, Wicket, Theo and everyone else in the story,
  and every character in the games.
- **Key names** as the help reads them: Enter, Escape, Space, Tab,
  Backspace, Page Up, Page Down, Home, End, the F keys, letter keys, Shift,
  Control, Alt, the arrow keys (Up, Down, Left, Right), and the controller's
  button names.
- **Brand and product names**: orinks.net, Discord, NVDA, JAWS, VoiceOver,
  Hearken, genny, Klang.
- **Numbers.** Keep every digit exactly as written.
- **Placeholders** in braces, like `{name}` or `{score}`. Move them wherever
  your grammar needs them, but keep the name inside the braces exactly.
- **Song titles.** No line names the tune a piece of music is based on, in
  English or in any language. Never add one.

## Core terms

| English | What it means |
| --- | --- |
| Wicket's | The whole app and the parlor it is set in. A name; never translated. |
| the parlor | The old games parlor the player looks after. |
| keeper | The player, as Mabel and Wicket call them. |
| the lobby | The launcher's main menu, the parlor's front room. |
| the Long Hall | Where every game's door and lamp are. A place name. |
| lamp | The light above a game's door. Finishing a game lights it for good. |
| game | One of the games in the parlor. |
| run | One play of a game, from start to results. |
| practice | A run that keeps no score and goes on no board. |
| tutorial | The guided first run that teaches a game. |
| results | What a run's end says: score, bests and what was unlocked. |
| best, your best | The player's highest score in a game. |
| score | Points from one run. |
| board, leaderboard | The online list of players' best scores. Pick one word for "board" and use it everywhere. |
| daily challenge | The run every player gets the same on one day. |
| Challenges | The menu of daily and special challenges. |
| event, special event | A game's own special day (a holiday night, a full moon). |
| special, holiday special | A game listed only in its holiday season. |
| Happening today | The lobby row listing today's events. |
| Seasonal, Action, Puzzle, Cozy games, Table, Story | The kinds of game, as the lobby sorts them. |
| Relaxed | A slower pace setting with its own bests. |
| pace | How fast a game runs: the Pace setting. |
| status | What S says: the state of the run right now. |
| help | What H or F1 opens: the game's help, in topics. |
| Settings | The settings menu. Its categories (Speech, Sound, Display, Controls, Games, Online, Updates) keep one word each. |
| Units | The setting for miles or kilometers and the like. |
| sound check | The menu that plays each of a game's sounds with its name. |
| Soundtrack | The menu that plays the game's music. |
| unlock, unlocked | Something a player earns and keeps. |
| door | A game's door in the Long Hall, or a door the story opens. |
| sitting | One visit to the parlor, from opening the app to leaving. |

## How the game talks

- Short. Every line is as short as it can be. Urgent facts come first; S
  gives the rest. A translation may be a little longer than the English,
  never much longer.
- Plain, friendly, spoken words. Address the player informally (Spanish
  "tú", French "tu", German "du") unless your glossary says otherwise.
- Never say a line is "spoken", "read aloud" or "announced": everything in
  Wicket's is spoken.
- Help and tutorial lines describe gameplay, never what a sound is like.
- No symbols a screen reader reads by name: no parentheses, slashes,
  percent signs, ampersands, em-dashes or ellipses.
