# Wicket's 1.7.0 alpha 1

This alpha brings everything in 1.6.0 to alpha players, and adds a
briefing before play in three games. Your saves and records carry over.

## From 1.6.0

- Game clocks wait while a line is still being spoken, and each timed game
  has a Pace row in Settings: relaxed, normal or quick. Order Up! has it
  too, and starts on relaxed. Relaxed keeps its own bests.
- Winter Wonderland has the Wish Desk, a new half with no clock.
- Rooftop Garden has four new seeds: strawberry, chilli, rose and jasmine.
- Report a problem, at the end of Settings, sends the game log to
  orinks.net and opens the report form in your browser.
- Help, tutorials and Settings help use plainer wording, and keys a game
  does not use are silent.
- The 1.6.0 notes list the rest.

## Briefing before play

- Order Up!, Belfry and Dragon Dance now open a short briefing before a
  run. It says what the run is, and the number keys play the sounds that
  run needs. Enter or Space starts.
- Settings in those three games has a new choice, Briefing before play.
  Turn it off to start runs at once.

## Story

- When you open an errand from Story and it leads into a lesson, the errand
  is spoken first, then the lesson.

## Signal Box

- On an event night, S gives the shift's numbers first. Press S again for
  the event. H no longer repeats it.

## Order Up!

- Help no longer mentions a Keys row that the title does not have.

Please tell us what feels too hard, too easy or unclear, above all in
Order Up!, Larkfield and Little Rapids.
