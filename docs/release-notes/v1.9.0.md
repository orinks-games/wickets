# Wicket's 1.9.0

This release rewrites help guides, tutorials and menu help across the
parlour in a clearer, more conversational voice, along with several game
and localization fixes. Your saves and records carry over.

## Help, tutorials and menus

- Rewrote help documents, interactive tutorials and menu help lines across
  every game and the launcher so instructions read naturally and explain
  what each game is about up front.
- Kept existing controls, menu labels and game rules unchanged.

## Fixes

- Settings opens without a pause.
- Snowfall Skate: each snow step is spoken once, instead of repeating at
  its edge.
- Harvest Feast: station and dish call-outs now speak as two sentences.
- Tide Pools and Tightrope: first-score and gust lines translate whole,
  and lane call-outs keep their side in every language.
- Alpha channel: Pebbles online matches now count in records, My games
  translates into all languages, leaving a match names the winner, and
  tied scores read as "tied at 1".
