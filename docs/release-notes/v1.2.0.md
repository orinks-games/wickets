## Added

- **Wicket's now updates itself.** It checks for a new version when it starts and asks before installing. Settings has Check for updates, and a switch to stop the check at start.
- Updates download only the files that changed, so most are small. Each one is checked against Wicket's own signature before it's installed.
- To get this version you still download it by hand. From now on, updates come to you.

## Fixed

- On a Mac, the game no longer stalls when speaking through VoiceOver.
- On a Mac, sounds that were missing from the app now play.
